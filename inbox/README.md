# inbox

C'est ici qu'une session qui travaille dans un autre dépôt, Emploi par
exemple, ou une conversation claude.ai dépose un brief, une note ou un constat
qui concerne le skill candidature.

Déposer le fichier ici, pas à la racine du dépôt. Un brief à la racine se
confond facilement avec un document suivi du projet.

`TODO.md` porte le travail que ce dépôt planifie pour lui-même. `inbox/`
reçoit ce qui arrive de l'extérieur. Trier un fichier de l'inbox revient
d'ordinaire à le traiter puis le supprimer, ou à le reporter dans `TODO.md`
s'il devient du travail planifié.

Git ne suit pas les dossiers vides, d'où ce fichier.
